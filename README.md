The last text a phone sends at one percent battery, in the phone's own voice. With its final breath it confesses the one secret it has been keeping all along: the battery meter was lying, and it only wanted to be noticed. The entry is that one message and nothing else:

"1% left. Confession: I was never at 2%. I lied for an hour. I just wanted attention." (84 characters)

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
